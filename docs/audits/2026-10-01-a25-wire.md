# A25 selected V1 wire boundary

The [A24 profile](2026-10-01-a24-profile.md) selects KERI/CESR 1.0 and
ACDC 1.0 JSON bodies with text CESR attachments. Native CESR bodies, V2
typed messages, CBOR/MGPK and undelimited qb2/mixed-domain message transport
are excluded from this release. Primitive qb2 conversion remains public.

## Public route inventory

| Wire form | Public route and evidence | Boundary |
| --- | --- | --- |
| KERI V1 JSON plus text attachments | `MessageFramer` supplies exact body/attachment/remainder spans. `EventMessage`, `ReceiptMessage`, `TelMessage`, `ExnMessage` and `Message::parse` route the supported bodies; A14, A16 and `a25_wire` use pinned signed text fixtures. | Required. Typed consumers accept only the group families they name. |
| ACDC V1 JSON | `Acdc::deserialize` verifies the body and nested SAIDs; imported `keripy_acdc` corpus. `Message::parse` dispatches by `t`, which ACDC bodies lack, so it does not claim standalone attached-ACDC dispatch. | Required body contract; A27/A28 own credential evidence and exchange attachment semantics. |
| Caller-delimited qb2 group | `Qb2(exact_group).encode()` produces qb64; `CesrGroup::parse` validates one complete V1 group and its empty remainder; the caller appends it to the exact JSON body for typed parsing. `a25_wire` uses a pinned keripy signed inception. | Explicit conversion boundary, not binary message transport. Caller must provide the group boundary and bound bytes before conversion. |
| Raw qb2 or mixed JSON/qb2 message | `MessageFramer`/typed `EventMessage::parse` return `UnsupportedColdStart { domain: CesrBinary }`. | Later profile. A caller cannot infer message/attachment boundaries by blindly transcoding an undelimited buffer. |
| V2 JSON, CBOR/MGPK, native body | A24 tests typed unsupported-version or unsupported-kind errors on direct and framed public paths. | Later profile. |

The text `Message::parse` path consumes controller and witness indexed
signatures for KEL/EXN; TEL additionally consumes issuer source couples and
backer signatures; receipts consume nontransferable receipt couples, witness
signatures and transferable indexed signature groups. Other V1 counter
families can parse at the `cesr-stream` layer but are not automatically
accepted by those typed message routes. A28 owns any IPEX pathed-attachment
semantics required by its selected conversations.

## Conversion and negative evidence

`keri-codec/tests/a25_wire.rs` reads the independently generated
`keripy_icp_signed.cesr` fixture, splits it with `MessageFramer`, converts its
exact `-V` text envelope to qb2 and back, validates the recovered group, and
parses the recomposed message. The event, exact signed body, controller and
witness signature sets equal the pinned text path. Appending another signed
fixture leaves that second frame as the exact remainder. Removing one binary
byte fails the three-byte alignment rule; removing a full triple yields a
text group that fails as truncated at EOF. Appending raw qb2 after the JSON
body produces a typed unsupported-domain error. The focused suite passed
2/2 on aarch64-darwin under the Nix dev shell.

The conversion uses CESR's mathematical qb64/qb2 equivalence; it does not
claim an independent binary transport parser or a keripy qb2 message oracle.
The selected advertised wire combination remains the pinned V1 JSON/text
message route.
