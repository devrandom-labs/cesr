# A11 retained-state retry evidence

Platform: aarch64-darwin, Rust 1.95.0, release profile. The benchmark case in `crates/keri-codec/tests/a10_auth_work.rs` is ignored by ordinary test runs and was executed explicitly 31 separate times after the mutable ingestion implementation:

```text
cargo test --release -p keri-codec --test a10_auth_work retained_retry_allocations -- --ignored --exact --nocapture
```

All 31 executions passed. The counting allocator recorded the same allocation pair in every run. The first four timings were discarded; 27 remaining timings are shown only to indicate resolution limits. All fixtures, signatures, parsed events, anchors, and prior owned state were prepared outside measured calls. The registry begins with one issued credential, so its `Cow<[CredentialChain]>` is owned; the candidate is a second distinct issue. The clone-based column includes cloning that owned registry and then calling the old consuming `ingest`. The mutable column calls `ingest_mut` on the retained registry. The rejected delivery lacks an accepted KEL anchor; the accepted delivery supplies it.

| Host operation | Allocation calls / requested bytes | Median µs | p10–p90 µs |
| --- | ---: | ---: | ---: |
| `KeyStateSnapshot::view()` | 0 / 0 | 0 | 0–0 |
| snapshot view, rejected KEL `ingest` | 0 / 0 | 2 | 2–2 |
| snapshot view, accepted KEL `ingest_mut` | 2 / 48 | 25 | 25–29 |
| cloned registry, rejected TEL `ingest` | 1 / 48 | 0 | 0–0 |
| retained registry, rejected TEL `ingest_mut` | 0 / 0 | 0 | 0–0 |
| cloned registry, accepted TEL `ingest` | 2 / 240 | 0 | 0–1 |
| retained registry, accepted TEL `ingest_mut` | 0 / 0 | 0 | 0–0 |

Sub-microsecond registry timings are below this instrument's resolution; allocation differences are the supported conclusion. The snapshot acceptance allocations are the two A10 single-signature verifier buffers, not snapshot conversion. This fixture demonstrates ownership cost with one existing credential; A12 separately measures cardinality and redesigns per-credential state. It does not claim bounded aggregate behavior at large registry size.

The executable public tests `a11_kel_retries_missing_signature_on_the_same_state`, `a11_delegated_rotation_retries_after_anchor_arrives`, `a11_registry_retries_missing_anchor_on_the_same_owned_state`, `a11_registry_rotation_rejects_late_receipt_without_advancing`, and the updated witness-rotation test assert actual retained-state retry and no partial advancement without cloning the state to survive failure. The delegated test checks both the plain missing-evidence rejection and a late incorrect anchor after signatures/rotation checks, before acceptance with the correct anchor.
